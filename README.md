# Bedtime Stories 🌙

A kids' app with short **bedtime stories**. Each story has a picture, the story text, and a sound effect, and you can change the text size from the settings.

## ✨ Features

- List of stories (The Bee & the Grasshopper, Chicken Little, The Hungry Cat, Lucky Ducky...)
- Story screen with image, text and a sound effect
- Settings screen to choose the text size (small / medium / large)
- The chosen size is saved and used next time

## 📚 What I Practiced

- `ListView` with a custom adapter
- Moving between activities and passing data with `Intent`
- Playing sounds with `MediaPlayer`
- Saving settings with **Preferences DataStore**
- Using `lifecycleScope` with coroutines
